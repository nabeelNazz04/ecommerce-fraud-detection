# Knowledge-Graph-Driven Explainable Fraud Detection in E-Commerce Using Graph Neural Networks

A final-year project exploring explainable fraud detection using Knowledge Graphs and Graph Neural Networks.

## Planned Technology Stack

- **Frontend:** React and Cytoscape.js
- **Backend:** Python and FastAPI
- **Graph Database:** Neo4j
- **Graph Learning:** GraphSAGE with PyTorch Geometric
- **Explainability:** GNNExplainer

## Project Status

Initial setup. Implementation and evaluation are planned in stages.

## Disclaimer

Dataset selection, implementation details, and evaluation results will be documented as the project develops.
